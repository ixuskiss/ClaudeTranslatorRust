# 계획 2 앱 수동 검증

실제 Windows와 Chrome에서 직접 실행하고 결과 칸을 채운다. 터미널에서는 화면 동작을 확인할 수 없어서, 아래 항목은 사람이 확인해야 한다.

## 준비

- 빌드(저장소 루트, PowerShell):

  ```
  cargo build -p ct-app --release
  ```

  실행 파일: `target\release\ct-app.exe`. release 빌드는 콘솔 창이 없고, 로그는 `%APPDATA%\ClaudeTranslator\logs\claudetranslator.<날짜>.log`에 쌓인다. 패닉은 `logs\crash.log`에 위치와 메시지만 남는다.
- 디버그로 로그를 콘솔에서 보려면 `cargo run -p ct-app`을 쓴다(디버그 빌드는 자동 시작 레지스트리를 건드리지 않는다).
- 로그를 더 자세히 보려면 `$env:LOG_LEVEL="DEBUG"`를 설정하거나 `%APPDATA%\ClaudeTranslator\.env`에 `LOG_LEVEL=DEBUG`를 쓴다.
- 확인할 때마다 로그에 원문·번역문이 남지 않았는지 함께 본다(작업 이름, 상태, 시간, 글자 수만 있어야 함).
- 실제 Claude CLI 자동 테스트는 PowerShell에서만 돌린다(Git Bash에서는 os error 5로 실패한다).

  ```
  $env:RUN_CLAUDE_CLI_LIVE_TESTS="1"; cargo test -p ct-llm --test live_cli -- --test-threads=1
  ```

## G. Ctrl+Ctrl 번역 보기 창

- 절차:
  1. Settings에서 Ctrl+Ctrl 표시 방식을 "원문 전체 · 번역 전체 보기 (기본값)"(whole_text)로 두고 문장 여러 개를 선택한 뒤 Ctrl+Ctrl을 누른다.
  2. "문장별로 보기"(per_sentence)로 바꿔 저장하고 다시 한다.
  3. 창이 열린 채로 다른 문장을 선택하고 Ctrl+Ctrl을 누른다.
  4. 창 제목 표시줄을 끌어 옮기고, 창 가장자리를 끌어 크기를 바꾼다.
  5. 짧은 문장, 긴 문단을 차례로 보기한다.
  6. 창 안을 클릭해 포커스를 준 뒤 Esc를 누른다.
  7. 선택 없이 Ctrl+Ctrl을 누른다.
- 기대 결과:
  - 1: 전체 번역이 한 덩어리로 뜨고 언어 표시가 붙는다.
  - 2: 문장별로 원문·번역이 짝지어 뜬다.
  - 3: 새 창이 생기지 않고 같은 창의 내용이 바뀐다.
  - 4: 창이 옮겨지고 크기가 바뀐다.
  - 5: 내용 길이에 맞춰 창 높이가 다시 맞춰진다(화면 작업 영역을 넘지 않음).
  - 6: 창이 닫힌다. 앱은 계속 실행된다(트레이 아이콘 유지).
  - 7: 창에 `텍스트를 선택한 후 Ctrl+Ctrl을 실행해주세요.`가 뜬다.
  - 결과가 뜨기 전에 창이 먼저 떠서 Chrome 포커스를 뺏지 않는다(캡처 후 창 표시).
- 결과: [ ] 통과 [ ] 실패

## H. 트레이 Target 메뉴와 Settings 반영

- 절차:
  1. 트레이 → Target Language에서 체크되지 않은 언어를 누른다.
  2. 체크된 언어를 누른다.
  3. Settings에서 ▲/▼로 Target 순서를 바꾸고 저장한 뒤 트레이 메뉴를 다시 연다.
  4. Settings에서 Alt+Alt 간격을 0.2초처럼 짧게 바꿔 저장하고, 앱을 재시작하지 않은 채 천천히(0.3초 간격) Alt를 두 번 누른다. 다시 길게(예: 0.6초) 바꿔 저장하고 같은 속도로 누른다. Ctrl+Ctrl 간격도 같은 방법으로 확인한다.

  - 1: 그 언어가 체크되고 `ja (2)`처럼 순서 번호가 붙는다.

  - 3: 트레이 메뉴의 번호가 Settings 순서와 같다.
  - 4: 짧은 간격에서는 발동하지 않고, 긴 간격에서는 발동한다(저장 즉시 반영, 재시작 불필요).

## O. 클립보드 보존 (실제 클립보드 왕복)

## Q. 자동 시작 (release 빌드만)

- 절차: release exe에서 Settings의 `Start ClaudeTranslator when I log in`을 켜고 저장한 뒤 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`을 본다. 끄고 저장한 뒤 다시 본다. 디버그 빌드(`cargo run -p ct-app`)에서도 켜고 저장해 본다.
- 기대 결과: release에서는 켜면 `ClaudeTranslator` 값(따옴표로 감싼 exe 경로)이 생기고 끄면 지워진다. 디버그 빌드는 레지스트리를 건드리지 않는다.
