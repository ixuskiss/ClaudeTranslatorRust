# 계획 3 한글 교정 수동 검증

실제 Windows와 Chrome에서 직접 실행하고 결과 칸을 채운다. 터미널에서는 화면 동작을 확인할 수 없어서, 아래 항목은 사람이 확인해야 한다. 아직 어느 항목도 통과로 표시하지 않았다.

## 준비

- 빌드(저장소 루트, PowerShell):

  ```
  cargo build -p ct-app --release
  ```

  실행 파일: `target\release\ct-app.exe`. 로그는 `%APPDATA%\ClaudeTranslator\logs\claudetranslator.<날짜>.log`에 쌓인다.
- Settings에서 Base Language는 `ko`, 한글 교정 방식은 `spelling`으로 시작한다(항목에서 바꾸라고 한 경우만 바꾼다).
- 시험 문장 예(오탈자 포함): `어제 회이에서 말씀드린 내요을 정리해서 보내드리겠읍니다.`
- 확인할 때마다 로그에 원문·교정문이 남지 않았는지 함께 본다(작업 이름, 상태, 시간, 글자 수만 있어야 함).
- 아래 순서로 키를 누른다: Ctrl+Alt+Alt는 Ctrl을 누른 채 Alt를 두 번, Alt+Ctrl+Ctrl은 Alt를 누른 채 Ctrl을 두 번 누른다.

## C1. Ctrl+Alt+Alt 교정 교체

- 절차: 오탈자가 있는 한국어 문장으로 각 앱에서 Ctrl+Alt+Alt를 누른다.
  1. Google Chat 작성창: 선택 없이(전체), 일부 선택해서 각각.
  2. Gmail 새 메일 본문: 선택 없이(전체), 일부 선택해서 각각.
  3. Google Slides 텍스트 상자: 전체, 일부 선택해서 각각.
  4. Google Docs: 문장 블록을 선택하고 한 번.
- 기대 결과:
  - 선택이 있으면 선택 부분만, 없으면 전체가 교정문으로 바뀐다(Docs는 선택한 블록).
  - 진행 중에 배지가 보이고 끝나면 사라진다. 메일·메시지는 전송되지 않는다.
