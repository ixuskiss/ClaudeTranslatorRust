# 계획 4 Google Sheets 수동 검증

실제 Windows와 Chrome의 Google Sheets에서 직접 실행하고 결과 칸을 채운다. 터미널에서는 화면 동작을 확인할 수 없어서, 아래 항목은 사람이 확인해야 한다. 아직 어느 항목도 통과로 표시하지 않았다.

## 준비

- 빌드(저장소 루트, PowerShell):

  ```
  cargo build -p ct-app --release
  ```

  실행 파일: `target\release\ct-app.exe`. 로그는 `%APPDATA%\ClaudeTranslator\logs\claudetranslator.<날짜>.log`에 쌓인다.
- Chrome에서 시험용 스프레드시트를 하나 만든다. 실제 업무 시트는 쓰지 않는다. 시험 전에 시트를 복사해 두고, 항목마다 원래 값으로 되돌린다.
- Settings에서 Base Language는 `ko`로 시작한다. `Target Languages`는 항목에서 말한 개수(1개 또는 3개 등)로 맞춘다. `Alt+Alt 교체 시 원문 포함`은 항목에서 바꾸라고 한 경우만 바꾼다.
- 시험 셀 예(한국어): `회의는 내일 오전 열 시에 시작합니다.` / `보고서를 금요일까지 보내 주세요.` / `점심은 사무실 근처에서 먹겠습니다.`
- 시험 셀 예(영어): `Please send the report by Friday.`
- 확인할 때마다 로그에 셀 내용·번역문·교정문이 남지 않았는지 함께 본다(작업 이름, 상태, 칸 수, 시간만 있어야 함).
- 키 입력: Alt+Alt, Ctrl+Ctrl. Ctrl+Alt+Alt는 Ctrl을 누른 채 Alt를 두 번, Alt+Ctrl+Ctrl은 Alt를 누른 채 Ctrl을 두 번 누른다.
- 범위 항목은 셀을 클릭하거나 드래그해서 선택만 한 상태(편집 중 아님)에서 실행한다.

## H1. 범위 Alt+Alt 교체

- 절차: 한국어 셀 3개(세로로 연속)를 선택하고 Alt+Alt를 누른다. 아래 조합을 모두 한다. 매번 시트를 원래대로 되돌린다.
  1. Target 1개, `Alt+Alt 교체 시 원문 포함` 꺼짐.
  2. Target 1개, 켜짐.
  3. Target 3개, 꺼짐.
  4. Target 3개, 켜짐.
- 기대 결과:
  - 선택한 셀 3개가 같은 위치에서 번역문으로 바뀐다. 셀 안에서 블록이 빈 줄로 나뉘어 순서대로 들어간다(켜짐이면 원문 → Target 순서대로, Target이 여러 개면 정한 순서대로).
  - 진행 중에 배지가 보이고 끝나면 사라진다. 다른 셀은 바뀌지 않는다.

## H3. 범위 Ctrl+Ctrl 표

  - 숫자 셀과 빈 셀이 표에 구분되어 표시된다.

## H4. 범위 교정(Ctrl+Alt+Alt / Alt+Ctrl+Ctrl)

- 절차: 오탈자가 있는 한국어 셀 2개와 맞는 셀 1개를 선택하고 각각 한다.

  2. Alt+Ctrl+Ctrl.
  3. 오탈자가 없는 셀만 선택해서 두 단축키를 각각 한 번씩.

## H5. 지원하지 않는 선택

- 절차: 아래 선택에서 Alt+Alt(링크 셀은 교체 쪽만)와 Ctrl+Ctrl을 각각 누르고 뜨는 문구를 기록한다.
  1. 행 전체(행 번호 클릭).
  2. 떨어진 여러 범위(Ctrl+클릭).
  3. 병합 셀이 들어간 범위.
  4. 필터로 숨긴 행이 들어간 범위.
  5. 링크가 있는 셀(교체만).
  6. 201칸 이상(예: 21행 × 10열).
- 기대 결과: 각각 `이 선택 범위는 지원하지 않습니다: {사유}` 형식으로 뜨고 시트가 바뀌지 않는다. 사유는 아래와 같다.
  - 1: `행·열 전체 선택은 지원하지 않습니다`
  - 2: `떨어진 여러 범위는 선택할 수 없습니다`
  - 3: `병합된 셀이 포함되어 있습니다`
  - 4: `숨겨진 행·열 또는 필터로 가려진 행이 포함되어 있습니다`
  - 5: `글자별 서식이나 링크가 있는 셀이 포함되어 있습니다. 해당 셀을 제외하고 다시 선택해주세요`
  - 6: `선택 범위가 너무 큽니다. 더 작은 범위를 선택해주세요`

## H7. 번역 중 시트·선택 변경

## H8. 셀 편집 중

- 절차: 셀을 더블클릭(또는 F2)해 편집 상태로 둔다.
  1. 셀 안의 글자 일부를 선택하고 Alt+Alt, 그다음 Ctrl+Alt+Alt.
  2. 선택 없이(셀 전체) Alt+Alt, Ctrl+Alt+Alt.
  3. 수식 셀(`=SUM(A1:A3)`)을 편집 상태로 두고 Alt+Alt.
  4. 번역 결과가 `=`로 시작하게 되는 문장(예: `=를 입력하세요`처럼 `=`로 시작하는 번역이 나오는 문장)으로 Alt+Alt.
- 기대 결과:
  - 1: 선택한 글자만 바뀐다.
  - 2: 셀 전체 교체는 설정이 켜져 있으면(기본값) 셀 전체가 바뀐다. 꺼져 있으면 `셀 전체 교체는 아직 검증되지 않아 꺼져 있습니다. 교체할 글자를 선택한 뒤 Alt+Alt를 눌러주세요.`(Ctrl+Alt+Alt는 `...Ctrl+Alt+Alt를 눌러주세요.`)가 뜬다.
  - 3: 수식은 `편집 중인 셀을 번역할 수 없습니다(수식·서식 또는 셀 상태를 확인할 수 없음).`(Ctrl+Alt+Alt는 `교정할 수 없습니다`)가 뜨고 수식이 바뀌지 않는다.
  - 4: `번역 결과가 =, +로 시작해 수식으로 해석될 수 있어 교체하지 않았습니다.`(Ctrl+Alt+Alt는 `교정 결과가 =, +로 시작해 ...`)가 뜨고 셀이 바뀌지 않는다.
